About this demo

This is a static shell of a Node.js / Express + EJS + MySQL application, built as a four-person group project for CTIS256. There is no server here: sign-up, login and the database are not part of the demo, so the two buttons above open the dashboards directly. Cart actions run on sample data in your browser.

We were learning the backend and frontend tooling as we built it, so most of the effort went into the server-side logic, routing and the data model. The styling was kept deliberately plain — it was never the point of the project.
